# Developer Xeno's Official Personal Website!

Developer Xeno is my personal portfolio website, built using Vite, React and Tailwind CSS.
I created this website to showcase my projects, skills and development path in a professional and modern way.

It has been built with performance and accessibility in mind and provides a great user experience with smooth animations, responsive design and an intuitive UI

## ✨ Features

⚡ Built with Vite for fast performance
⚛ Built with React's modern features
🎨 Stylish and accessible UI with Tailwind CSS
📱 Responsive design for all screen sizes
🌙 Modern UI with smooth transitions
💼 Sections for projects, skills and experience
🚀 Optimised for performance, accessibility and SEO
🔧 Easy to edit and update

## 🛠️ Tech stack

React
Vite
Tailwind CSS
JavaScript (ES6+)
HTML5
CSS3

## 🎯 Purpose

Developer Xeno aims to provide a professional online presence to display my work, learnings and development path to others. It also serves as a playground to experiment with modern tools and technologies related to web development.
